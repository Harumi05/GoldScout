# Notas técnicas

- El EA no fuerza una operación por hora; evalúa H1 y puede decidir NO TRADE.
- Las noticias son contexto, no una predicción garantizada.
- Si el feed mundial queda desactualizado, el EA mantiene el bloqueo según sus parámetros.
- El dashboard usa múltiples fuentes para evitar depender de una sola.
- Las sesiones/centros se usan como contexto de liquidez/volatilidad; una apertura no implica automáticamente pullback.
