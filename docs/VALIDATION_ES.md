# Validación recomendada

1. Compilar el EA en MetaEditor y confirmar 0 errores.
2. Ejecutar paper mode y verificar varias evaluaciones H1.
3. Verificar que cada evaluación muestra H4/H1, EMA, RSI, ADX, ATR, volumen, estructura, LONG/SHORT, noticias, sesión y motivo de bloqueo.
4. Ejecutar Strategy Tester con datos de ticks reales del broker y después una prueba out-of-sample/walk-forward.
5. Ejecutar demo live antes de cualquier cuenta real.
